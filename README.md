## 👨‍💻 About Me

I am a **Java Backend Developer with 4+ years of experience** building secure, scalable, and high-performance software for healthcare, automotive, and enterprise environments.

My core expertise includes **Java, Spring Boot, Microservices, REST APIs, Kubernetes, Docker, GitLab CI/CD, SQL, Redis, RabbitMQ, automated testing, and observability**.

Some highlights from my experience:

- Improved API response time by **35.7%**, reducing latency from **350 ms to 225 ms**.
- Implemented **10+ features and COBOL-to-Java integrations** for critical Mercedes-Benz enterprise systems.
- Supported healthcare platforms serving **300,000+ external users** and approximately **5,000 internal users**.
- Maintained **4 critical healthcare applications across 16 environments**.
- Implemented application security improvements using HTTP headers, secure cookies, and TLS 1.2/1.3.
- Worked with Kubernetes, Docker Swarm, GitLab CI/CD, OpenTelemetry, SigNoz, Kibana, and Redis in production environments.

I enjoy working on backend architecture, distributed systems, performance optimization, application security, observability, and software modernization.
